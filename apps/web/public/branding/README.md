# Daubert Cromwell branding

The application displays the unmodified official Daubert Cromwell logo from the company's public website:

`https://daubertcromwell.com/wp-content/uploads/daubertcromwell_2lines.png`

This location is reserved for approved local brand assets when they are supplied by Daubert Cromwell.

## Favicon

The favicon uses the approved full "DAUBERT MEXICO" medallion (no cropped or redesigned mark). All files derive from `daubert-logo-source.png` (400×400, unmodified original):

- `favicon.ico` — 16, 32 and 48 px, circular alpha mask (transparent corners).
- `favicon-32.png` — 32 px, same circular mask.
- `apple-touch-icon.png` — 180×180, opaque white background (iOS fills transparency with black).

They are referenced from `apps/web/index.html`. Regenerate them from the source file if the approved artwork changes.
